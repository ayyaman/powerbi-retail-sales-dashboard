# Perakende Satış Analizi | Power BI

## Proje Hakkında

Bu projede, perakende satış verileri Microsoft Power BI kullanılarak analiz edilmiş ve görselleştirilmiştir. Marka, il, mağaza, satış kanalı, ürün grubu ve ürün bazında satış performansının incelenmesi amaçlanmıştır.

## Projenin Amaçları

- Markalara ve ürün gruplarına göre satış performansını incelemek.
- İllere ve mağazalara göre satış dağılımını analiz etmek.
- Satış kanallarının performansını değerlendirmek.
- Satış tutarı ve iade tutarı verilerini incelemek.
- Kampanyalı satışların performansını analiz etmek.
- Müşteri sayısındaki değişimleri değerlendirmek.
- LFL verileri üzerinden karşılaştırmalı performans analizleri yapmak.
- Tarih verilerini kullanarak satış eğilimlerini incelemek.
- Verileri Power BI görselleştirmeleriyle anlaşılır hâle getirmek.

## Veri Seti

Projede kullanılan veri seti aşağıdaki alanları içermektedir:

- Marka
- İl
- Satış Kanalı
- Mağaza
- Enlem
- Boylam
- LFL
- Ürün Grubu
- Ürün
- İade Tutarı
- Satış Tutarı
- Kampanyalı Satış
- Müşteri Sayısı
- Tarih

## Kullanılan Teknolojiler

- Microsoft Power BI
- Veri Analizi
- Veri Görselleştirme
